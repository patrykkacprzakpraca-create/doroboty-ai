# Node.js 24.22.3 update

## Goal

Pin the project and its CI to the Node.js 24.22.3 LTS security release, and verify the workspace with the official Node.js and npm distribution.

## Acceptance criteria

- The version file used by CI and local version managers selects 24.22.3.
- A verified official macOS arm64 package provides both node and npm for local testing.
- The application and package behavior are checked with the new runtime. Record any test limitation and review the feature register.

## Verification and review

- Downloaded the official macOS arm64 archive and matched its SHA-256 to the [Node.js release page](https://nodejs.org/en/blog/release/v24.22.3). The workspace-local copy reports Node.js 24.22.3 and npm 11.19.1.
- The existing GitHub Actions workflow reads `.nvmrc`. The participant package retained the pinned version and excluded the workspace-local runtime.
- `./scripts/verify` passed formatting, design-system checks, lint, types, 31 unit tests, the baseline verifier and static build. Its browser step failed to bind the loopback port in the default sandbox. The Playwright-managed Chromium was unavailable, so all 42 browser journeys ran successfully in installed Chrome using a temporary configuration. Gemini was disabled during verification.
- Compared the static artifact fingerprint before and after the update. The files were byte-identical. Reviewed the behavior register and found no behavior changes requiring an update.
